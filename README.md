## Featured Project

### Singapore HDB Resale Price Drivers & 2031 Forecast

An individual analysis of 977,756 HDB resale transactions from January 1990 to May 2026. The project uses SQL and Excel for data preparation, exploratory analysis, regression modelling, forecasting and model evaluation.

[View the interactive report](https://chetankish.github.io/singapore-hdb-resale-price-drivers-2031-forecast/)
